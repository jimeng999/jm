设置 BYOK Key，三步搞定

简单三步，开始使用极梦AI BYOK 模式。

1 注册账户，获取您的 API Key
2 设置您的 OpenAI/DeepSeek 等 Key
3 开始调用，零差价使用 AI 能力
Terminal
# 1. 设置您的 BYOK Key curl https://api.jimeng.ai/v1/user/api-keys \ -X POST \ -H "Authorization: Bearer $JIMENG_KEY" \ -d '{ "provider": "openai", "api_key": "sk-your-openai-key-here" }' # 2. 开始调用（零差价！） curl https://api.jimeng.ai/v1/chat/completions \ -H "Authorization: Bearer $JIMENG_KEY" \ -d '{ "model": "gpt-4o", "messages": [{"role": "user", "content": "Hello!"}] }' # 3. 查看已设置的 Keys（脱敏显示） curl https://api.jimeng.ai/v1/user/api-keys \ -H "Authorization: Bearer $JIMENG_KEY"
常见问题

有疑问？这里有答案

BYOK = Bring Your Own Key（携带你自己的 Key）。您使用自己的 OpenAI/DeepSeek API Key 调用 AI 模型，我们不收取任何差价费用。只在您没有配置 Key、需要使用平台 Key 时，才收取 30% 的服务费。

您的 API Key 采用 AES 加密存储，我们无法访问明文数据。加密密钥与您的账户绑定，只有在调用 AI 服务时才会临时解密使用。

您可以享受每日 5 次 DeepSeek 免费体验。如果需要更多调用，可以设置自己的 Key（零差价），或者使用平台 Key（加价 30%）。

两者都支持 BYOK 无限调用。主要区别：Pro 用户享有每日 10 次平台 Key 免费体验、智能模型路由、详细用量分析面板和优先客户支持。

BYOK 模式下，您只需支付模型提供商的费用（OpenAI/DeepSeek 等官方价格）。如果您使用平台 Key，我们会加收 30% 作为服务费。订阅费用与 API 调用费用分开计算。
